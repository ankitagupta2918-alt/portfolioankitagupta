# Ankita Gupta — Portfolio

A light, premium, glassmorphism-style portfolio built with plain HTML, CSS and JavaScript.

## Before deployment
1. Put your resume at `assets/Ankita_Gupta_Resume.pdf`.
2. Replace `YOUR_EMAIL@example.com` in `index.html` and `script.js`.
3. Tomorrow, replace the project placeholder links with your actual GitHub repositories.
4. Add the three real certificate images/PDFs in `assets/` and update the certificate cards.
5. Add your final GitHub profile URL.

## Deploy on Vercel
- Upload this folder to a GitHub repository.
- In Vercel, import that repository.
- Framework preset: Other.
- Build command: leave blank.
- Output directory: leave blank.
- Deploy.

This is a static site, so no Node.js build is required.
